# Notes affichées dans « Nouvelle version » du canal de test (3 premières lignes ; une ligne par point)
Impression d'un geste : « Imprimer » ouvre la fenêtre d'impression du navigateur tout de suite, sur les pages de l'aperçu ; le PDF ne se fabrique que pour « Enregistrer en PDF », avec une barre de progression sur le bouton.
Un seul bouton « Imprimer » par écran, dans la barre du bas, le même sur iPhone et ordinateur ; sur iPhone le bouton montre la préparation du PDF puis ouvre le menu Partager (Phomemo, AirPrint).
Document trop long même réduit : la fin passe sur une page « suite » dans l'aperçu, à l'impression et dans le PDF ; rien n'est masqué.
