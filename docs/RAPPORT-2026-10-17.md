## 1. Cotation : libellés de la convention

- **« VG + MU »** partout (écran Express, mode complet, journal, synchronisation). Le code interne « U » est devenu « MU », même tarif (22,60 €). Les anciennes lignes du journal marquées « U » s'affichent « MU ».
- **MU ou MD, jamais les deux** : cocher MD au journal retire MU.
- **Vérifié** :
  - jour : VG + MU, ou VG + MD ;
  - nuit : G + CRN / VG + VRN ;
  - milieu de nuit : G + CRM / VG + VRM ;
  - dimanche et férié : G + CRD / VG + VRD ;
  - âge : MEG avant 6 ans, MOP à partir de 80 ans ;
  - ECG : DEQP003 ;
  - aucun code U, MDN, MDI, MM ni F.
- Test : `tests/test_cotation17.py` (30 tests, iPhone et ordinateur).
- **À trancher** : en visite, le supplément ECG qui se cote avec DEQP003 est **YYYY490 (9,60 €)** selon la nomenclature CSMF 2023/2024. CLAUDE.md et les mémos des fiches écrivent « YYYY090 ». Packs ne l'ajoute pas encore au calcul.
- Tarif de DEQP003 : Packs utilise 14,26 € ; un site commercial annonce 14,77 € depuis octobre 2026, non confirmé par ameli.
