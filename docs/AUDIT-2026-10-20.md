# Audit et état des lieux — 20/10/2026 (branche ia, v41v ; outil de garde main = v41k)

## A. Architecture (inchangée)
Application web d'un seul fichier (`index.html`, ~19 000 lignes) + service worker (`sw.js`), sans serveur : GitHub Pages, données chiffrées sur l'appareil (AES, code personnel), profil `profil.json` chiffré par phrase maître (identité, cachet, clé API). Dossier `test/` = même application construite depuis la branche `ia` avec stockage et cache séparés.

## B. Fonctionnalités opérationnelles, conservées
- Catalogue de fiches (Pack SOS Médecins, `PACKS`) : ordonnances, biologie, imagerie, soins, courriers, consignes, mémos ; gabarits de doses au poids et à l'âge ; alertes (interactions, contre-indications, âge, sexe, grossesse) ; « maintien avec motif » tracé.
- Express visite (téléphone) : patient → fiche proposée → dictée → impression et validation (5 à 6 touchers), favoris.
- Tournée : import des fiches par capture, ordre optimal, destination finale et heure de fin (réglages), appel, « Je suis arrivé », mode voiture, bilan de garde, kilomètres.
- Dictée : grand champ, brouillon chiffré à chaque frappe, dictées récentes 48 h ; observation par appareil ; examen complet par défaut (normaux types à valider d'un geste).
- Compte rendu, courriers (spécialiste, médecin traitant), certificats, arrêt de travail, cotation (convention SOS Médecins Orléans, ECG, IK), note d'honoraires, journal de garde chiffré.
- Impression : PDF seul (jamais la page web), une page par document, cachet jamais recouvert, deux documents par feuille quand possible, réimpression, « Patients validés » 12 h.
- IA : pseudonymisation sur l'appareil (DPO 15/10/2026), garde-fous (nombres, posologies, jetons), file hors ligne, plafond mensuel, consommation.

## E. Limites connues, à décider
- Clé API dans le navigateur et appel direct à l'API : usage personnel seulement ; la pseudonymisation seule ne vaut pas conformité HDS. Relais côté serveur à prévoir avant tout partage (docs/FEUILLE-DE-ROUTE.md).
- Tests sur appareil réel (micro iPhone, impression AirPrint) : non réalisables depuis l'environnement de développement ; simulés (WebKit iPhone 13 pour les PDF).
- Un test d'interface (menu ⋯ à 375 px en grand texte) échoue parfois quand 25 suites tournent en parallèle ; il passe seul.
